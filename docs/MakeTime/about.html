About

This project was designed to help you create a fun outline of your daily schedule so that you can organise yourself better and have time to do all the activities you want!

Please note that each activity is only in one block with the time you set. If you want to have two study time blocks, you must set, for example, one activity called ‘morning study’ and another called ‘afternoon study’.

If you save your schedule in JSON, you can import it again to edit it. We do not store any of your data. Thank you for participating!
